# VladiMir-TV 2.0 — новый проект (TV + Android)

## Включено в исходный код
- Собственная красно-тёмная иконка V и баннер Fire TV.
- Тёмное домашнее меню с крупными плитками: ТВ, фильмы, сериалы, избранное, плейлисты, телефон/QR.
- Русский, немецкий, английский язык интерфейса через Settings / Einstellungen / Настройки.
- Несколько локальных M3U-ссылок, редактирование, удаление, категории, избранное, проигрывание Media3.
- Локальный QR-веб-пульт: поиск названий каналов/фильмов/сериалов, запуск видео на ТВ и добавление M3U через телефон. Телефон и ТВ должны быть в одной сети; телефон использует системную клавиатуру.
- Адаптация к Android-телефону (сенсорное управление) и Fire TV Stick (пульт).

## Ограничения, которые нельзя скрывать
- Это исходники, а не APK. В этом окружении не установлен Android SDK/Gradle, поэтому APK НЕ собран и не проверен на устройстве. GitHub Actions настроен на assembleDebug.
- Плитки «Фильмы» и «Сериалы» показывают записи, которые удаётся определить из M3U group-title. Нет отдельного API видеотеки, постеров, EPG, архива или полнотекстового поиска на сервере провайдера.
- QR-веб-пульт работает ТОЛЬКО в общей локальной сети, а не удалённо через интернет. Общих/индивидуальных облачных плейлистов пока нет: нужен отдельный сервер, защищённые учётные записи и привязка устройств.
- Локальный веб-пульт использует HTTP с временным секретом в QR/URL; не открывайте порт 8765 в интернет. M3U-ссылки могут содержать секретные токены. Не делитесь QR и не публикуйте личные M3U в GitHub. Добавление через веб-форму в локальной сети использует URL-параметры, поэтому для конфиденциальных ссылок лучше дождаться защищённого облачного управления.
- Не гарантируется наличие субтитров или нескольких звуковых дорожек: зависит от потока и поддержки плеера.

## Как начать новый проект
1. Создайте НОВЫЙ пустой GitHub-репозиторий (или замените содержимое старого только после резервной копии).
2. Загрузите СОДЕРЖИМОЕ архива в корень, сохраняя скрытую папку `.github/workflows`.
3. GitHub Actions -> Build VladiMir TV APK -> Run workflow.
4. После успешной сборки скачайте артефакт APK, затем испытайте на Fire TV и Android-телефоне.
5. Не публикуйте APK как готовый продукт до испытаний.
